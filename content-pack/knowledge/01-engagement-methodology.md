# Engagement methodology / 安全测试项目方法

一个可靠的测试任务包含：目标、授权、范围、排除项、时间窗、测试账号、速率限制、停止条件、证据位置、报告受众。

推荐状态机：`intake → scope-confirmed → discovery → validation → evidence → review → report → retest`。

重要区分：发现开放端口不等于发现漏洞；工具告警不等于已证实影响；无法复现的现象应保留为待复核。每次操作都应可回答“对哪个资产、以什么身份、何时、用什么请求、得到什么响应”。

English retrieval keywords: engagement, authorization, scope, rules of engagement, evidence, reproducibility, stop condition, retest.
