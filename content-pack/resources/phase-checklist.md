# Phase checklist / 阶段检查表

## Intake

- [ ] 资产和所有者明确
- [ ] 授权参考号和时间窗明确
- [ ] 排除项、限速和停止条件明确

## Discovery

- [ ] 记录扫描源、DNS、时间和工具版本
- [ ] 先被动，再低影响探测
- [ ] 结果去重并标注证据来源

## Validation

- [ ] 使用测试账号和测试对象
- [ ] 复现步骤可回滚
- [ ] 未读取不必要的真实数据

## Closeout

- [ ] 所有发现有置信度和修复建议
- [ ] 敏感信息已脱敏
- [ ] 未测试范围和残余风险已列出
- [ ] 需要回归验证的项目已登记
