# 认证、会话与访问控制评估

## 目标

验证 `{{application}}` 的身份认证、会话生命周期和对象级授权。只使用 `{{test_accounts}}` 提供的测试身份和测试数据。

## 检查表

- 登录、注销、密码重置、MFA 和会话超时是否符合预期。
- Cookie 的 Secure、HttpOnly、SameSite、范围和轮换是否合理。
- 普通用户访问自身对象与他人对象时，服务端是否重新授权。
- API 的批量、分页、导出和错误响应是否泄露跨租户信息。
- 权限变更、账号禁用和 token 撤销是否即时生效。

## 证据规则

每个结论至少保存：角色、对象 ID 类型（使用测试对象）、原始请求/响应摘要、预期行为、实际行为、重复验证结果。禁止把真实个人数据复制到报告。

## 输出

按“前置条件 → 操作 → 观察 → 影响 → 修复 → 回归测试”编写发现；无法稳定复现时标记为 `needs-review`，不要升级为确定漏洞。
